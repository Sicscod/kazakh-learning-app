# Kazakh Learning App — MVP (версия 1)

Дата: 2026-10-02
Репозиторий: Sicscod/kazakh-learning-app (Flutter)
Статус: утверждено (2026-10-02)

## 1. Цель

Мобильное приложение (Flutter: Android, iOS, web) для изучения казахского языка людьми, говорящими по-русски, по-английски и (позже) по-китайски. Проект для портфолио с прицелом на мини-стартап.

Версия 1 должна быть законченным продуктом, который можно показать: вход, выбор языка и уровня, изучение слов, повторение, прогресс и текстовый чат с ИИ-репетитором. Остальные навыки видны в интерфейсе как «скоро».

### Критерии успеха версии 1
- Новый пользователь проходит путь: регистрация → язык обучения → уровень → тема → карточки → тест → видит прогресс, без ошибок.
- Контент: уровни A1 и A2, по 5 тем, по 20 слов в теме (200 слов), переводы на русский и английский, проверенные человеком.
- Чат с ИИ-репетитором отвечает на казахском с пояснениями на языке обучения.
- Всё работает на бесплатных тарифах (Supabase Free, бесплатная модель ИИ).
- Логика повторений и серии дней покрыта unit-тестами.

### Уровни
Шкала в приложении — CEFR A1–C2. Официальная система КАЗТЕСТ использует пять уровней A1–C1, поэтому темы A1–C1 сверяются с тематикой КАЗТЕСТ, а C2 остаётся уровнем «свободного владения» сверх КАЗТЕСТ. Это даёт продукту понятное позиционирование: «готовит к КАЗТЕСТ».

### Вне версии 1
Reading, Listening, Writing, Speaking (голос), тест на определение уровня, контент B1–C2, китайские переводы контента, оплата, уведомления. Каждое — отдельный следующий проект со своим дизайном.

## 2. Языки

| Роль | Языки в v1 | Позже |
|---|---|---|
| Изучаемый язык | казахский (kk), кириллица | латиница (по мере перехода Казахстана) |
| Язык обучения (переводы, объяснения) | ru, en | zh |
| Язык интерфейса | kk, ru, en | zh |

- Строки интерфейса — ARB-файлы `lib/l10n/app_kk.arb`, `app_ru.arb`, `app_en.arb` (Flutter `gen-l10n`). Китайский добавляется новым файлом `app_zh.arb`.
- Переводы контента хранятся в отдельной таблице `translations`, поэтому новый язык обучения = новые строки в базе, без изменения кода и схемы.
- Язык интерфейса по умолчанию — язык обучения пользователя; меняется в профиле и на приветственном экране (существующий переключатель kz → ru → en).

## 3. Путь пользователя и экраны

1. **Приветствие** — существующий экран «СӘЛЕМ! / тіркелу / кіру» с переключателем языка. Вёрстка переделывается с абсолютных координат на адаптивную (колонка по центру), чтобы не обрезаться на экранах шириной 360.
2. **Регистрация / Вход** — email + пароль (Supabase Auth). Ошибки показываются на языке интерфейса.
3. **Онбординг** (только после первой регистрации):
   1. Язык обучения: Русский / English / 中文 (中文 неактивен с пометкой «скоро»).
   2. Уровень: A1, A2, B1, B2, C1, C2 (B1–C2 неактивны с пометкой «скоро»).
4. **Главный экран — навыки**: карточки навыков Сөздер (Слова), Reading, Listening, Writing, Speaking, ИИ-репетитор. Активны: Сөздер и ИИ-репетитор. Остальные — с замком и подписью «скоро». Сверху: серия дней и число выученных слов.
5. **Сөздер → список тем** выбранного уровня, у каждой темы прогресс (выучено X из 20). Сверху кнопка «Повторить» с числом слов, которые пора повторить.
6. **Тема → выбор режима**: Карточки или Тест.
7. **Карточки**: казахское слово (и пример), по нажатию переворачивается и показывает перевод. Кнопки «Знаю» / «Не знаю». На обороте — маленькая ссылка «Сообщить об ошибке». Сессия — все слова темы, которые ещё не выучены (если все выучены — все 20).
8. **Тест**: 10 вопросов. Вопрос — казахское слово, 4 варианта перевода (1 верный + 3 случайных из той же темы). Каждый второй вопрос — наоборот: перевод → 4 казахских варианта. В конце — результат и список ошибок.
9. **Повторение**: карточки из слов всех тем, у которых подошёл срок повторения (см. 5.1).
10. **ИИ-репетитор**: чат. Первое сообщение — приветствие репетитора на казахском с переводом. Под полем ввода — счётчик оставшихся сообщений на сегодня.
11. **Профиль**: имя, email, уровень, язык обучения, язык интерфейса, статистика, выход.

## 5. Правила

### 5.1 Интервальное повторение (система Лейтнера)
- У каждого слова пользователя есть «коробка» `box` от 0 до 5 и дата `due_at`.
- Интервалы по коробкам: 0 → сразу, 1 → 1 день, 2 → 3 дня, 3 → 7 дней, 4 → 14 дней, 5 → 30 дней.
- Ответ «Знаю» в карточках или верный ответ в тесте: `box = min(box + 1, 5)`, `due_at = сейчас + интервал(box)`.
- «Не знаю» или неверный ответ: `box = 0`, `due_at = сейчас`.
- Слово считается **выученным**, когда `box >= 3`.
- «Пора повторить» = слова, у которых `box >= 1` и `due_at <= сейчас`.

### 5.2 Серия дней
- День засчитывается, когда пользователь завершает сессию карточек, тест или повторение (чат не считается).
- Дата берётся по часовому поясу устройства.
- Если последний засчитанный день — вчера: серия +1. Если сегодня: без изменений. Если раньше вчера или никогда: серия = 1.
- `profiles.streak` и `profiles.last_active_date` обновляются одной функцией на сервере (RPC), чтобы два устройства не испортили счёт.

### 5.3 Ошибки и сеть
- Нет интернета или ошибка сервера: экран показывает сообщение на языке интерфейса и кнопку «Повторить». Ответы в карточках/тесте, не отправленные из-за сети, сохраняются в памяти и отправляются при следующем успешном запросе в той же сессии.
- Неверный пароль, занятый email, слабый пароль — отдельные понятные сообщения.

## 6. Данные (Supabase)

| Таблица | Поля | Доступ |
|---|---|---|
| `levels` | `code` (A1…C2), `sort`, `is_available`, `content_version` | чтение всем |
| `topics` | `id`, `level_code`, `slug`, `sort`, `icon` | чтение всем |
| `words` | `id`, `topic_id`, `kk`, `example_kk`, `sort` | чтение всем |
| `translations` | `entity_type` (topic/word/example), `entity_id`, `lang`, `text` | чтение всем |
| `profiles` | `user_id`, `display_name`, `level_code`, `learning_lang`, `ui_lang`, `streak`, `last_active_date`, `created_at` | только владелец |
| `word_progress` | `user_id`, `word_id`, `box`, `due_at`, `correct_count`, `wrong_count`, `updated_at` | только владелец |
| `chat_messages` | `id`, `user_id`, `role` (user/assistant), `content`, `created_at` | только владелец |
| `content_reports` | `id`, `user_id`, `word_id`, `comment`, `created_at` | вставка — авторизованные, чтение — никто из клиентов |

- Названия тем хранятся в `translations` (`entity_type = topic`, включая `lang = kk`).
- Профиль создаётся триггером при регистрации.
- Контент загружается SQL-файлами из `supabase/seed/`.

## 7. ИИ-репетитор

- Приложение вызывает Edge Function `tutor`; ключ модели хранится только в секретах Supabase.
- Функция: проверяет пользователя, проверяет дневной лимит (30 сообщений пользователя в сутки), берёт из профиля уровень и язык обучения, берёт последние 20 сообщений чата, отправляет модели, сохраняет ответ в `chat_messages`, возвращает его.
- Модель подключается через один адаптер с OpenAI-совместимым API (`TUTOR_BASE_URL`, `TUTOR_API_KEY`, `TUTOR_MODEL` в секретах). Старт — бесплатная `glm-4.7-flash` (Zhipu): `https://open.bigmodel.cn/api/paas/v4` (нужна китайская телефонная верификация) или международный портал z.ai. Смена модели — только смена секретов, без изменения приложения.
- Перед началом работ над экраном чата — проверка качества: 20 тестовых диалогов на A1/A2; если модель путает казахский с другими тюркскими языками или делает много ошибок, меняем модель до разработки экрана.
- Рабочее имя репетитора: **Ұстаз** (меняется в одном месте — системной инструкции и строках интерфейса).
- Системная инструкция: ты — Ұстаз, дружелюбный учитель казахского; уровень ученика {level}; отвечай простым казахским на этом уровне; после ответа — короткий перевод и пояснения на {learning_lang}; мягко исправляй ошибки ученика с объяснением; предлагай темы из уровня; не выходи из роли учителя.
- Если модель недоступна: сообщение «Ұстаз сейчас отдыхает, попробуй позже» на языке интерфейса; сообщение пользователя не теряется и не списывается из лимита.

## 8. Контент v1

- A1: Танысу (знакомство), Отбасы (семья), Сандар (числа), Тағам (еда), Қала (город).
- A2: Уақыт (время), Ауа райы (погода), Оқу және жұмыс (учёба и работа), Саяхат (путешествия), Мәдениет (культура и традиции).
- 20 слов в теме, у каждого — пример предложения; переводы на ru и en.
- Источники: собственные материалы; общественное достояние (народные сказки, пословицы, произведения Абая); факты о культуре допускаются из открытых источников, но тексты пишутся своими словами. Учебники и сайты под авторским правом не копируются. Википедия — только с указанием источника.
- Процесс: черновик готовит Claude → проверка казахского человеком (Санжар или знакомый преподаватель) → загрузка в seed.

## 9. Ограничения бесплатных тарифов и риски

| Риск | Мера |
|---|---|
| Supabase Free засыпает после 7 дней без активности | Бесплатный GitHub Actions cron раз в 3 дня делает лёгкий запрос к API |
| Supabase Free: 500 МБ базы, 500 тыс. вызовов функций в месяц, 50 тыс. активных пользователей | Для v1 с запасом; чат ограничен 30 сообщениями в день на пользователя |
| Доступ к supabase.co из Китая бывает медленным | Контент (темы, слова, переводы) кэшируется на устройстве после первой загрузки; повторная загрузка только при смене версии контента (`content_version` в `levels`) |
| Бесплатная модель ИИ может плохо знать казахский | Проверка качества до разработки экрана чата (раздел 7) |
| Ошибки в казахском контенте | Каждое слово проверяет человек до загрузки; в приложении кнопка «Сообщить об ошибке» на карточке пишет в таблицу `content_reports` |

## 10. Тестирование

- Unit: `srs.dart` (все переходы коробок, «выучено», «пора повторить»), `streak.dart` (вчера / сегодня / разрыв / первый день), `quiz_builder.dart` (4 разных варианта, верный среди них, чередование направления).
- Widget: экран теста (выбор ответа → следующий вопрос → результат), экран приветствия (переключатель языка меняет текст).
- Старый шаблонный `test/widget_test.dart` удаляется.
- Попутные исправления: убрать из `pubspec.yaml` несуществующие шрифты Inter-Regular/Inter-Bold.
